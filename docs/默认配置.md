# 默认配置说明

初始化项目（`srelay init`）后会在项目根生成 `.sessionrelay/config.json`。
**下面的值就是出厂默认** —— 不写这一节，用户永远不知道系统在替他做什么决定。

配置文件是**浅合并**：你只写想改的键，其余用默认值。

```jsonc
{
  "version": "1.0",
  "capture": {
    "mode": "full",              // full | meta | off
    "idle_threshold_min": 10,    // 会话静止多久算"结束"，触发抽取
    "cooldown_hours": 6,         // 同一会话两次采集的最小间隔
    "sources": ["claude-code", "zcode", "codex", "qoder", "dsh"],
    "ignore_sources": []         // 永不采集的来源
  },
  "search": {
    "tokenizer": "jieba",        // 中文分词器
    "min_hits_hint": 3,          // 命中少于这个数就提示"换个词"
    "auto_days": 30              // 不带时间参数时默认搜最近 N 天
  },
  "privacy": {
    "ignore_file": ".sessionrelayignore",   // 按 .gitignore 语法写
    "export_redact": true                    // 导出交接包默认脱敏
  },
  "identity": {                  // 由 init 自动填入 project_id，别手改
    "project_id": "proj_xxx"
  },
  "archive": {
    "enabled": true,
    "hot_days": 30,              // 超过 N 天的会话正文转"派生摘要"，原文可从客户端重放
    "workflow_days": 7,          // 工作流类会话更早归档（信息密度低）
    "check_every_min": 60
  },
  "recompute": {
    "check_every_min": 360       // 抽取规则重算检查周期（6 小时）
  },
  "decay": { "enabled": false }
}
```

## 几个值得解释的默认值

### `capture.mode` = `full`

三档：

| 档 | 行为 |
| -- | ---- |
| `full` | 采集**全部**消息（默认）。信任基础是三张底牌：本地存储、项目内、可一键删除 |
| `meta` | 只存元数据与决策，不存正文 |
| `off` | 完全不采集；只能靠 `srelay save` 手动存 |

### `archive.hot_days` = 30（不是 60）

实测（2026-10-17，用户批准调整）：落盘系数 3.1× 正文，messages+FTS 占库 **94~97%**。
缩短热窗可省 agent1super **36.9%** / music **69.3%**；
**结论与经验全保留**，正文仍可从客户端会话文件重放 —— 所以这是"省体积"，不是"删记忆"。

### `decay.enabled` = `false`（默认关）

时间衰减模块已实现、已接线，但**默认关闭**，理由是「先量再接」：
当前库最老的决策只有 66 天，而「三个月前」这个场景还没真实出现，
所以线上开了差异也很小 —— 这不代表它没用，只代表**现在还用不上**。

打开后只乘**排序分数**、不过滤：老记录仍能搜到，只是排得靠后。

> ⚠️ 经验（lesson）那条线**不要**用这个衰减 —— `store/lesson-gate.ts` 已有
> `DECAY_PER_DAY = 0.0083` 的线性年龄扣分（用于注入阈值判决，会真的过滤）。
> 两处一起用 = 衰减两次。

### `privacy.export_redact` = `true`

导出 `.hop` 交接包时默认脱敏（手机号/邮箱/token 类）。要传原文给同事就显式 `--no-redact`。

## 改了怎么生效

| 改什么 | 要不要重启 |
| ------ | ---------- |
| `capture.*` / `archive.*` / `recompute.*` | 守护进程**下一轮**读取，最多 60 秒 |
| `search.*` / `decay.*` | 下一次检索立即生效（不缓存） |
| `privacy.*` | 下一次导出/采集生效 |

想把配置恢复出厂值：删掉 `.sessionrelay/config.json`，再跑一次 `srelay init`（**不会**动已采集的记忆）。
